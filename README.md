# FYND – AI Smart Retail Trolley

FYND is an AI-powered smart retail trolley system designed to modernize supermarket shopping experiences using computer vision and intelligent navigation.

## Features
- AI Product Detection
- Automated Billing System
- Live Rack Navigation
- 3D Neon Store Map
- Smart Product Finder
- Real-Time Cart Updates
- Interactive Shopping UI

## Technologies Used
- HTML
- CSS
- JavaScript
- AI Concepts
- Computer Vision

## Project Vision
FYND aims to reduce checkout waiting time, improve customer shopping experience, and bring futuristic automation into retail stores.
